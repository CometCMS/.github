CometCMS is a single PHP folder you upload to your server. Then you open `/admin` in your browser. It runs on PHP 8.2+ and stores everything as JSON files, so it works on the cheapest hosting you can find.

### ✨ Highlights

- 🎨 **Visual Page Builder**: server-rendered websites with shared layouts, themes, headers, footers and menus
- 🧩 **Custom fields and content types** bound to your designs, with forms and submissions built in
- 🔌 **Optional headless REST API and embedded MCP endpoint** for Next.js, Astro, mobile apps or AI agents
- 🔐 **Fine-grained access tokens**, scoped by action, content type, media category and field
- 🌍 **Built-in localization** with per-language URLs, `hreflang` and sitemaps
- 💾 **One-click backups** of all content, media and settings
- 🧱 **Extensions**: ship your own page-builder blocks, components and theme presets as ZIPs

### 🚀 Get started

1. Download the [latest release](https://github.com/CometCMS/CometCMS/releases/latest)
2. Upload the folder to your web host via FTP or your host's file manager
3. Open `https://yourdomain.com/admin` and create your admin account

You can find the rest in the [documentation](https://cometcms.github.io/documentation/).
